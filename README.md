
# 🏥 Healthcare Analytics Dashboard

## 📌 Project Overview
This Healthcare Analytics Dashboard is an interactive data analytics project created using **Power BI, Excel, and SQL** to analyze patient demographics, laboratory performance, doctor efficiency, treatment insights, and healthcare trends.

The dashboard helps healthcare organizations monitor important KPIs, identify patient patterns, optimize operations, and support data-driven decision-making through interactive visualizations.

---

# 🎯 Business Problem
Healthcare organizations generate massive amounts of patient and treatment data daily.  
Without proper analytics, it becomes difficult to:

- Understand patient demographics
- Monitor treatment and lab performance
- Track doctor efficiency
- Identify abnormal medical patterns
- Analyze healthcare costs
- Improve operational efficiency

This dashboard converts raw healthcare data into meaningful business insights for better healthcare management.
